Limits to keep in mind

  • The data comes from Open-Meteo's weather reconstruction, which reads about 1–2 °C cooler than IMD thermometers on the hottest days, so it finds slightly fewer heatwaves.
  • IMD officially declares a heatwave only when two stations in a region qualify on two days in a row. This project labels each city on its own.
  • The first day of a heatwave is the hardest to call: the model caught of them. Adding weather-forecast inputs would help most.

The RBF kernel, explained

The technique is a Support Vector Machine (SVM) with a Radial Basis Function (RBF) kernel. Here is what each part does, and a live demo you can play with.

The classifier

SVM

Sorts each day into one of two groups, heatwave next or normal next. It draws the boundary between the groups as far as possible from both, so new days near the edge are still sorted safely. It only remembers the past days near that boundary, called support vectors.

How it compares days

Kernel

A rule for measuring how similar two days are. The SVM never looks at the boundary directly: it asks the kernel how similar today is to each remembered day. Change the kernel and the shape of the boundary changes.

The kernel we use

RBF

Similarity = exp(−γ × distance²). Two identical days score 1, very different days score close to 0. Because similarity fades with distance, the boundary can curve around the heatwave corner instead of being a straight line.

Type of boundary
Small γ: far-away days still count, so the boundary is smooth. Large γ: only very close days count, so the boundary wraps around single dots and memorises them (overfitting).
Small C allows a few dots on the wrong side for a simpler boundary. Large C tries to get every past day right.

From similarity to a decision

This is exactly what step 3 of the Forecast tab does, with all 12 inputs and 1,446 remembered days.

score = Σ (similarity to remembered day × its weight α × (+1 heatwave / −1 normal)) + bias

Score above 0 means heatwave side, below 0 means normal side; 0 is the boundary. The weight α is learned in training and is capped by C. Platt scaling then turns the score into a percentage.

Did the kernel help?

The RBF kernel catches more heatwaves at a similar false-alarm level. The gain over a straight line is modest because the inputs were designed to follow IMD's rule closely, which already makes the problem easier.
